five-byte NativeParm program. Dispatch authenticates those original metadata,

consumes EndFunctionParms. Inputs are copied in caller-frame context, including

The existing VM refuses unaudited partial/overflow FString clears.

truncate. The packed launcher's concrete error provider is not established, so
the runtime explicitly refuses at that provider before interning. The pure

## Actual arena, first spelling and lifetime

The host uses a SHORT detached NameStringArenaStage during this native call,
not a stage retained across arbitrary VM callbacks. AddOriginalName returns
the earliest genuine spelling for an existing compare identity; the uppercase
comparison row is not original display spelling. Case variants allocate no new
name identities. New names receive real NameString indices, and typed consumers
can resolve those same arena identities immediately after native return.

Its explicit IncrementalOriginalName mode owns one operation. Actual existing
compare/spelling buckets are traversed and charged, with original first-spelling
identity authenticated at compare+1 (and None0). For a missing name, two strings
and two map nodes stage separately while actual live Names/bucket capacity is
unchanged. Validation charges the exact future populated-bucket traversal and
hashing before the allocation-free move/node-transfer suffix. Real insufficient
capacity uses the existing full-growth path before any delta is created. The
default multi-name staging API and resource limits remain unchanged.

All UTF16/transport/folding/arena traversal and temporary storage are admitted
before work/allocation. The native prebuilds its result, validates the arena and
combined state budget, then performs an allocation-free publication suffix.
Its name growth receives a separate process-lifetime credit retained in the
live-state ledger even after map/runtime retirement. Limits are unchanged.
That credit measures nonnegative NET live-arena growth, not a per-name allocation
count: replacing an overallocated old buffer can reduce total retained capacity
while admitting new actual names. Pure arena tests independently meter all
staging peaks; owned integration must verify actual new identity/work and
positive later net-growth credit, not require positive net growth on every name.

This preserves the embedding's EXISTING process-permanent FName contract used
by real constructors, package metadata and Input Alias imports. World rollback
still restores name-bearing UObject values, save bytes, revision, lookup and GC;
it does not invalidate successfully interned process names behind other cached
real NameString handles. Refused staging/invalid input adds no name identity.
The diagnostic API documents this distinction instead of claiming an arena undo.
